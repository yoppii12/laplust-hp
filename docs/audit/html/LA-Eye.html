Features

LA-Eyeの特長

LAplust Eye

詳しく見る

Feature 01

対象物の"特徴"に注目

キズ・汚れ・欠け、または形の特徴を覚えし、人と同じように大まかな特徴を捉えて検出することが可能。定まった形だけでなく不定形な特徴も正確に検出。

Feature 02

少数データで高精度な検査

独自アルゴリズムにより、不良画像30～50枚程度の少数データで高精度AIを実現。必要に応じてデータを追加し、再学習も可能。

Feature 03

専用レンズや専用カメラは不要

見たいモノに適した計測手法を選べる。
既設のカメラ・顕微鏡・ファイバースコープ・X線写真etc.

Feature 01
